# スケジュール管理

複数の開発プロジェクトについて、工程ごとの工数または期間を月×旬（上旬・中旬・下旬）のマトリクスで管理し、チームのキャパシティと照合する Web アプリです。

## 概要

- 工程は **工程マスタ** で共通定義し、**プロジェクト設定** で表示／非表示・入力方式・総工数・期間を個別に設定します。
- **工数入力** の工程は 0.1 人日刻みで旬ごとに割り当て、**期間のみ** の工程は開始旬〜終了旬を色付きセルで表示します。
- **祝日・休業日マスタ** に登録した日と土日を除いた営業日数から、旬ごとのキャパシティ（人日）を算出します。
- 割当合計が安全率（既定 80%）を超えると黄色、キャパシティ到達で赤色で警告します。

## セットアップ（Windows）

`python` コマンドではなく `py` ランチャーを使います。

```powershell
# プロジェクトフォルダに移動してからコマンドを実行します
py -3.14 -m venv .venv
.\.venv\Scripts\Activate
pip install -r requirements.txt
python app.py
```

- venv 有効化後は、環境内の `python` / `pip` が使えます。
- ブラウザで http://127.0.0.1:5000 を開きます。
- 初回起動時に `schedule.db`（SQLite）が自動作成されます。

## データベースの切り替え

アプリが参照する DB は、プロジェクト直下の `schedule.db` です（`db.py` の `DB_PATH`）。  
別データを確認したいときは、アプリを止めたうえでファイルをリネームして切り替えます。  
以下は PowerShell 向けの手順です。Windows Terminal でコマンドプロンプトを使っている場合は、タブの `∨` から PowerShell を起動してください。

```powershell
# PowerShell で実行すること（コマンドプロンプトでは Rename-Item は使えません）

# 1. アプリを停止する（Ctrl+C）

# 2. いま使っている DB を退避
Rename-Item schedule.db schedule_work.db

# 3. 確認したい DB を schedule.db にする
Rename-Item schedule_check.db schedule.db

# 4. アプリを再起動
python app.py
```

元に戻すときは、同様にリネームし直します。

```powershell
# PowerShell で実行すること

# アプリ停止後
Rename-Item schedule.db schedule_check.db
Rename-Item schedule_work.db schedule.db
python app.py
```

- `schedule.db` が無い状態で起動すると、空の DB が新規作成されます。
- パス自体を変えたい場合は `db.py` の `DB_PATH` を編集してください。

## 画面ごとの機能

### スケジュール

メイン画面。プロジェクト×工程×月×旬のマトリクスで工数割当とキャパシティを確認・入力します。

| できること         | 説明                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| 表示期間の変更     | 開始月〜終了月（YYYY-MM）を指定して表示。設定画面のデフォルト値が初期表示に使われます。            |
| 工数の入力         | **工数入力** に設定された工程のセルに、0.1 人日刻みで入力。入力は自動保存されます。                |
| 期間の確認         | **期間のみ** に設定された工程は、指定期間のセルが色付き（●）で表示されます。入力はできません。     |
| 工程別サマリ       | 左端に総工数・割当済・差分（総工数 − 割当済）を表示。差分が 0 でない場合は警告色になります。       |
| キャパシティ確認   | 表下部に旬ごとの営業日数・キャパ（人日）・割当合計を表示。安全率超過は黄色、キャパ到達は赤色です。 |
| プロジェクトへ移動 | プロジェクト名をクリックすると編集画面へ移動します。                                               |

- 左端のプロジェクト名・工程名・メタ列は横スクロール時も固定表示されます。
- スケジュールに表示されるのは、プロジェクト設定で **表示** にした工程のみです。

### プロジェクト

プロジェクトの一覧・作成・編集・削除を行います。

**一覧画面**

| できること | 説明                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 一覧表示   | プロジェクト名と、各工程の設定内容（総工数／割当済、期間、非表示）を一覧で確認できます。 |
| 新規作成   | 「新規作成」からプロジェクトを追加します。                                               |
| 編集       | プロジェクト名をクリックして編集画面へ移動します。                                       |
| 削除       | プロジェクトと関連する工数・期間データを削除します。                                     |

**作成・編集画面**

| できること         | 説明                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| プロジェクト名     | 名称を設定します。                                                                                                       |
| 工程の表示／非表示 | チェックボックスで、そのプロジェクトで使う工程を選びます。非表示の工程はスケジュールに出ません。                         |
| 入力方式           | 工程ごとに **工数入力** または **期間のみ** を選択します（例: 結合試験を外部委託で期間管理、自社実施で工数管理、など）。 |
| 表示順             | ↑↓ ボタンで工程の並び順を変更します。                                                                                    |
| 総工数             | 工数入力の工程について、目標の総工数（人日・0.1 刻み）を設定します。                                                     |
| 期間               | 期間のみの工程について、開始月・開始旬〜終了月・終了旬を設定します。                                                     |
| 入力方式の切替     | 工数入力 ↔ 期間のみ を切り替えると、不要になった側のデータ（割当工数または期間）はクリアされます。                       |

- 新規プロジェクト作成時、初期工程は工程マスタの定義に従います（既定: 設計 / 実装 / 単体テスト / 結合試験 / 本番リリース）。
- 結合試験は新規プロジェクトでは **期間のみ** が初期値、その他の工程は **工数入力** が初期値です。

### 工程マスタ

全プロジェクト共通の工程定義を管理します。

| できること   | 説明                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------- |
| 工程名の編集 | 一覧から名称を変更して更新します。                                                            |
| 背景色の設定 | 水色・橙色・緑色・藤色の 4 色から選択。スケジュール上のセル色に反映されます。                 |
| 表示順の変更 | ↑↓ ボタンで並び替え、「並び順を保存」で確定します。新規プロジェクトの初期順序にも使われます。 |
| 工程の追加   | 画面下部から新しい工程を追加します。                                                          |
| 工程の削除   | 工程と、全プロジェクトに紐づく工数・期間データを削除します。                                  |

- **入力方式**（工数入力／期間のみ）は工程マスタでは設定しません。プロジェクト設定で工程ごとに指定します。

### 祝日・休業日マスタ

営業日計算に使う休日を管理します。

| できること | 説明                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| 日付の追加 | 画面上部のフォームから日付（YYYY-MM-DD）を登録します。名称は任意で、空のまま登録できます。 |
| 名称の編集 | 一覧の名称欄を編集し、「更新」で保存します。                                               |
| 削除       | 登録済みの日付を削除します。                                                               |

- 土日に加え、ここに登録した日付は営業日から除外されます（祝日・会社休業日の両方に使えます）。

### 設定

アプリ全体のパラメータと表示設定を管理します。

| できること         | 説明                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| メンバー人数       | 旬ごとのキャパシティ計算に使用します（キャパ = 営業日 × 人数）。        |
| 安全率（%）        | 割当合計が「キャパ × 安全率」を超えた旬を黄色で警告します（既定 80%）。 |
| デフォルト表示期間 | スケジュール画面の初期表示月（開始〜終了）を設定します。                |
| カラーテーマ       | ライト / ダーク / システムに合わせる から選択します。                   |

- ヘッダーのテーマ切替からも、表示中の画面を離れずにテーマを変更できます（設定画面の保存とは別に即時反映）。

## 計算の考え方

- **旬**: 各月を上旬（1〜10 日）・中旬（11〜20 日）・下旬（21 日〜月末）に分割します。
- **営業日**: 旬内の平日のうち、祝日・休業日マスタに登録された日を除いた日数です。
- **キャパシティ（人日）**: 営業日 × メンバー人数。
- **警告**: 割当合計 > キャパ × 安全率 → 黄色、割当合計 ≥ キャパ → 赤色。
