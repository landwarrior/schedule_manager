# スケジュール管理

複数の開発プロジェクトの工数を、月の上旬・中旬・下旬に割り当ててキャパシティと照合する Web アプリです。

## 機能

- プロジェクト工程: 設計 / 実装 / 単体・内部結合 / 試験T / 本番リリース
- 試験T以外は 0.1 人日刻みの工数を旬単位で手入力
- 試験Tは開始旬〜終了旬の期間表示のみ
- 祝日は手動登録（土日＋祝日を除いた営業日を計算）
- 旬ごとのキャパ = 営業日 × メンバー人数
- 割当合計が安全率（既定80%）を超えると黄色、キャパ到達で赤色
- カラーテーマ（ライト / ダーク / システムに合わせる）

## セットアップ（Windows）

`python` コマンドではなく `py` ランチャーを使います。

```powershell
cd D:\program_src\schedule_manager
py -3.14 -m venv .venv
.\.venv\Scripts\Activate
pip install -r requirements.txt
python app.py
```

- venv 有効化後は、環境内の `python` / `pip` が使えます。
- ブラウザで http://127.0.0.1:5000 を開きます。
- 初回起動時に `schedule.db`（SQLite）が自動作成されます。

## 画面

| 画面 | 内容 |
|------|------|
| スケジュール | 表示期間の工数入力・試験T期間・キャパサマリ |
| プロジェクト | 名称・総工数・試験T期間の登録 |
| 祝日 | 休業日の手登録 |
| 設定 | メンバー人数・デフォルト表示期間 |
